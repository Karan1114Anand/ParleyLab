# ParleyLab

ParleyLab is an AI negotiation simulator. You practice real negotiation scenarios — salary offers, freelance contracts, apartment leases, equity splits — against an AI opponent whose strategy is driven by a trained reinforcement learning agent (PPO) and whose dialogue is generated by an LLM. After every move, an independent critic evaluates your technique in real time against established negotiation theory.

Built for the **IEEE AI/ML Hackathon** by team **Hell's Kitchen**.

---

## Running Locally

You need two terminals: one for the backend, one for the frontend.

### Prerequisites

- Python 3.10+
- Node.js 18+
- A [Groq API key](https://console.groq.com/keys) (opponent agent)
- A [Gemini API key](https://aistudio.google.com/apikey) (critic agent)

### Setup

```bash
git clone https://github.com/Karan1114Anand/ParleyLab.git
cd ParleyLab
cp .env.example .env
# Open .env and set your GROQ_API_KEY and GEMINI_API_KEY
```

### Backend

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cd backend
uvicorn main:app --port 8000
```

Wait for `Orchestrator ready` before starting the frontend.

### Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000), pick a scenario, and start negotiating.

## LLM Configuration

Each agent uses a dedicated model. Set the following in `.env`:

```env
# Opponent Agent — Groq (primary)
GROQ_API_KEY=gsk_...
PARLEYLAB_OPPONENT_PROVIDER=groq
PARLEYLAB_OPPONENT_MODEL=gpt-oss-120b

# Critic Agent — Gemini
GEMINI_API_KEY=your-key-here
PARLEYLAB_CRITIC_PROVIDER=gemini
PARLEYLAB_CRITIC_MODEL=gemini-2.0-flash-lite

# Fallback — Ollama (used when Groq is unavailable)
OLLAMA_BASE_URL=http://localhost:11434
PARLEYLAB_FALLBACK_MODEL=llama3.1:8b
```
